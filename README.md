# 🍔 Food Delivery Application

A modern, fast, and responsive Full-Stack Food Delivery Web Application. Users can browse through various restaurants, check menus, add items to their cart, and place orders seamlessly.

---

## 🚀 Features

* **User Authentication:** Secure login and registration for users.
* **Interactive Menu:** Browse dishes by categories with dynamic pricing.
* **Cart System:** Real-time add, update, and remove items from the cart.
* **Search & Filter:** Easily search for specific food items or filter by cuisine.
* **Responsive UI/UX:** Fully optimized for Mobile, Tablet, and Desktop screens.
* **Order Summary:** Clear breakdown of items, taxes, and delivery charges before checkout.
